# 🌿 COP31 Hackathon Oyun Projesi (GameUp)

Bu çalışma alanı, COP31 Türkiye (Antalya) temalı hackathon için geliştirilen web oyunlarını barındırır.

## 📁 Projeler
- **[Eko-Ayrıştırıcı: Sıfır Atık Laboratuvarı](./eko-ayristirici/)**  
  Antalya temalı, 3 kademeli, 5 hazneli, eğitici tuzak nesneli akıllı geri dönüşüm ve refleks oyunu.
  - 🌐 **Canlı Web Sitesi:** [https://mehmetdenizli.github.io/eko-ayristirici-cop31/](https://mehmetdenizli.github.io/eko-ayristirici-cop31/)
  - 📂 **Proje Klasörü:** `./eko-ayristirici/`

### 🚀 Oyunu Yerel Olarak Çalıştırma
```bash
cd eko-ayristirici
npm install
npm run dev
```
Tarayıcınızda `http://localhost:5173/` adresine gidin.
